# PartnerOps Google Ads Campaign Draft

Goal: run a small validation campaign with minimal manual upkeep. Use Google Ads App campaigns once the App Store and Google Play listings are live, then let Google's automated placement and bidding test Search, Play, YouTube, Discover, and Display inventory.

## Campaign Setup

- Campaign type: App promotion
- Objective: App installs
- Platforms: Android first if Google Play is live earlier; iOS once App Store listing is approved
- Geo: United States, United Kingdom, Canada, Australia, Sweden
- Language: English
- Budget: start low, then scale only after install quality is visible
- Optimization event: installs for first test; switch to an in-app action later if analytics/subscription events are added
- Exclusions: under 18, dating hookup intent where available, medical/health diagnosis keywords

## Positioning

Core promise:

Private relationship memory and planning for people who mean well but forget details.

Do say:

- Remember dates, preferences, sizes, support windows, and gift ideas.
- Get practical prompts before birthdays, anniversaries, and stressful weeks.
- Local-first V1 with no partner account and no message scraping.

Do not say:

- Track her.
- Predict her mood.
- Never disappoint her again.
- Secret relationship app.
- Medical, therapy, or diagnosis claims.

## First Test Readout

After 3 to 7 days, check:

- Cost per install by platform and country.
- Store listing conversion rate.
- Screenshot drop-off if available.
- Search terms or asset signals when available.
- Whether installs cluster around gift/anniversary language or privacy/local-first language.

If install cost is poor:

- Replace generic relationship copy with occasion-driven copy.
- Test screenshots that lead with Panic Helper and Prompt Coach.
- Narrow countries before increasing budget.

If install cost is acceptable:

- Add in-app conversion events before scaling.
- Add a pricing/subscription experiment only after retention signal exists.
