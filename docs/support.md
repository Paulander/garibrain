# PartnerOps Support Draft

PartnerOps is a private relationship memory and planning app.

## Help

For support, use the public support email or support form configured before launch.

Suggested support email:

```text
support@partnerops.app
```

## Common Questions

### Is PartnerOps a couples app?

No. V1 is a private personal memory and planning tool for one user.

### Does PartnerOps sync to a backend?

No. V1 is local-first and works without a PartnerOps backend.

### Does PartnerOps use HealthKit or Health Connect?

No. Cycle-based support reminders are manually configured estimates and are not medical advice.

### Does PartnerOps hide itself as another app?

No. PartnerOps provides privacy protections such as app lock and neutral notifications, but does not implement deceptive camouflage or fake calculator mode.

### How do I delete data?

Open Settings, then use Delete all local data.
